# 🐱 Cat Jump  
### Vertical Endless Platformer – Android

🎮 **Cat Jump** es un juego indie de plataformas vertical estilo *endless jumper*, desarrollado **100% en Android nativo**, donde el jugador controla a un gato que debe ascender infinitamente superando plataformas, obstáculos y desafíos cada vez más difíciles.

Proyecto personal creado de punta a punta, con foco en **rendimiento**, **arquitectura limpia** y **gameplay fluido**, incluyendo un **motor de juego propio** sin uso de engines externos.

## 🚀 Características Principales

- 🧠 Motor de juego custom desarrollado desde cero
- ⚙️ Física y colisiones personalizadas
- 🧱 Generación procedural de niveles con dificultad progresiva
- 🎨 28 skins desbloqueables con:
  - Patrones únicos  
  - Variaciones de color  
  - Escalas y estilos visuales propios
- 💥 5 tipos de obstáculos con comportamientos diferenciados
- ⚡ 2 power-ups con efectos distintivos
- 🐾 Gameplay fluido optimizado a **83 FPS**

---

## 🛠️ Tech Stack

- **Lenguaje:** Kotlin  
- **UI:** Jetpack Compose  
- **Design System:** Material Design 3  
- **Arquitectura:** MVVM + Clean Architecture  
- **Patrones:**  
  - Repository Pattern  
  - Use Cases  
  - Inyección de dependencias  

---

## 🧩 Arquitectura

El proyecto sigue principios de **Clean Architecture**, separando responsabilidades para mejorar mantenibilidad y escalabilidad.

**Capas principales:**

- **Domain**
  - Lógica de juego
  - Física y colisiones
  - Reglas de negocio
  - Use Cases

- **Data**
  - Repositorios
  - Gestión del estado del juego
  - Configuración de skins y power-ups

- **UI**
  - Jetpack Compose
  - Renderizado del juego
  - Estados reactivos y manejo de input

---

## ⚙️ Motor de Juego

El motor fue desarrollado específicamente para este proyecto e incluye:

- 🕒 Game loop propio
- 📐 Sistema de coordenadas y colisiones optimizado
- 🧮 Física custom para saltos, caídas y rebotes
- 🎯 Control preciso del input del jugador
- 🚀 Rendimiento estable incluso en dispositivos de gama media
